# Резюме-білдер

Веб-застосунок для створення та управління резюме, побудований на Django.

---

## Запуск проєкту

```bash
cd generatormain
python manage.py runserver
```

Відкрий у браузері: http://127.0.0.1:8000

---

## Облікові записи

### Адміністратор
| Поле | Значення |
|------|----------|
| Ім'я користувача | `admin` |
| Пароль | `Admin1234!` |
| Роль | Адміністратор |
| Django Admin | Так (`/admin/`) |

### Звичайний користувач
| Поле | Значення |
|------|----------|
| Ім'я користувача | `user` |
| Пароль | `User1234!` |
| Роль | Користувач |

---

## Сторінки авторизації

| Дія | URL |
|-----|-----|
| Вхід | `/accounts/login/` |
| Реєстрація | `/accounts/register/` |
| Профіль | `/accounts/profile/` |
| Панель адміна | `/accounts/admin/users/` |
| Django Admin | `/admin/` |

---

## Скидання / перестворення користувачів

Якщо потрібно скинути паролі або перестворити акаунти:

```bash
python manage.py create_users
```

Команда використовує `get_or_create` — безпечно запускати повторно.
